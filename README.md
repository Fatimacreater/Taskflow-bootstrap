# TaskFlow

TaskFlow is a responsive task management UI built using HTML and Bootstrap 5.

## Live Demo

https://fatimacreater.github.io/Taskflow-bootstrap/

## Features

- Responsive Navbar
- Dashboard with task summary cards
- Add New Task form
- Task category and priority selection
- Due date input
- Recent Tasks list
- Task status and priority badges
- Edit and Delete buttons
- Delete confirmation modal
- Bootstrap alerts
- Responsive layout

## Technologies Used

- HTML5
- Bootstrap 5

## Purpose

This project was created to practice Bootstrap basics such as:

- Grid system
- Responsive design
- Spacing utilities
- Flexbox utilities
- Cards
- Forms
- Buttons
- Badges
- List groups
- Alerts
- Modals
- Navbar
